# 采煤机电机启停故障诊断树

> 数据来源：4段微信小程序操作录屏。本文档用于复刻原有诊断流程；未录制分支不做推测。

## 安全说明

- 本资料由既有小程序录屏整理，仅用于故障诊断逻辑复刻和培训，不替代设备厂家手册、矿方安全规程及现场技术负责人指令。
- 涉及带电测量、短接接触器控制回路、绝缘测试、拆线或更换模块的操作，仅限具备资质且获得授权的人员执行；必须落实停电、验电、放电、闭锁挂牌和防误送电措施。
- 录屏中的“短接”步骤属于高风险诊断手段。程序实现时必须先展示安全确认，不得将其设计为普通用户可直接执行的无条件操作。
- 严禁用铜丝替代保险或绕过空气开关、保护回路及联锁。

- **hp_q001** [问题] 注意：所有电机启动都有按钮防压死保护，按钮按下时间不足3秒或超过5秒都将无法启动，请规范操作。采煤机上电启动后，显示器进入正常监视画面，所有模块状态均显示为绿色。按下油泵启动按钮3～5秒，显示器是否有油泵电机启动提示（有语音配置的采煤机同时有语音提示）？
  - `有` → `hp_q002`
    - **hp_q002** [问题] 显示器有油泵电机启动提示（有语音配置的采煤机同时有语音提示），说明采煤机已经开始执行启动命令。提示结束后，油泵电机是否正常启动？
      - `已启动` → `hp_q003`
        - **hp_q003** [问题] 提示结束后油泵电机正常启动。启动以后，油泵电机是否可以持续平稳运转？
          - `可以` → `hp_q004`
            - **hp_q004** [问题] 油泵电机持续运转，说明泵电机启动回路工作正常。请观察显示器是否有牵引（或截割）被泵电机闭锁提示？
              - `有` → `hp_q005`
                - **hp_q005** [问题] 有牵引（或截割）被泵电机闭锁提示，说明泵电机接触器吸合后反馈没有进入系统。请检查MOC-JX4.7在泵接触器吸合后是否有F+24V。
                  - `有24V` → `hp_r001`
                    - **hp_r001** [结论] 在泵接触器吸合后，MOC-JX4.7上可以测量到F+24V，说明电源及泵接触器辅助触点正常。在确认MOC-JX4插头没有问题后，请直接更换MOC模块。
                  - `没有` → `hp_r002`
                    - **hp_r002** [结论] 请依次检查F24V到泵接触器辅助触点、再由辅助触点到MOC-JX4.7之间的线路，找到断路点并处理。
              - `没有` → `hp_r003`
                - **hp_r003** [结论] 没有显示牵引（或截割）被泵电机闭锁提示，系统允许进一步操作采煤机，说明泵电机启动电路正常。
          - `不能` → `hp_q006`
            - **hp_q006** [问题] 油泵电机启动后立即停止运转。请观察显示器是否有故障提示。注意：不是所有故障信息都在监视画面中显示，需要进入故障查询才能看到。
              - `有故障` → `hp_r004`
                - **hp_r004** [结论] 根据系统提示的故障信息进行针对性处理。在系统模块“最近停机原因”中查到的停机代码，可在本小程序的系统故障模块中查看。
              - `无故障` → `hp_q007`
                - **hp_q007** [问题] 没有故障提示，多数是控制线路有虚接，接触器吸合时因振动再次断开；也可能是接触器自身无法吸持或模块不能保持。可手持短线短接MOC-JX2.5和MOC-JX2.8，检查接触器是否能吸合并保持。
                  - `可以` → `hp_r005`
                    - **hp_r005** [结论] 短接MOC-JX2.5和MOC-JX2.8后，接触器保持吸合状态，说明问题在MOC模块。请更换MOC模块后再次尝试启动油泵。
                  - `不能` → `hp_r006`
                    - **hp_r006** [结论] 短接MOC-JX2.5和MOC-JX2.8后，接触器不能保持吸合状态，说明接触器吸持线圈存在问题，请直接更换接触器。
      - `未启动` → `hp_q008`
        - **hp_q008** [问题] 提示结束后油泵电机没有启动，请认真观察显示屏是否有故障提示。注意：不是所有故障信息都在监视画面中显示，需要进入故障查询才能看到。
          - `有故障` → `hp_q009`

                  - `正常` → `hp_r008`

              - `220V漏电` → `hp_q011`
                - **hp_q011** [问题] 屏幕提示220V漏电，请检查220V电源对地绝缘。使用万用表直接测量对地绝缘即可，严禁使用摇表测试。
                  - `漏电` → `hp_r009`
                    - **hp_r009** [结论] 查找漏电原因，处理漏电。这类故障多数由线路捆扎不合理、绝缘皮磨破造成。
                  - `绝缘正常` → `hp_r010`
                    - **hp_r010** [结论] 经过测试绝缘良好，说明220V漏电模块误动作。临时措施：将MOC-JX4.9上的线从端子排上拆除并包扎。请尽快更换220V漏电模块。
          - `无故障` → `hp_q012`
            - **hp_q012** [问题] 油泵电机没有启动，屏幕也没有任何故障提示，可能原因：1.有停止信号进入控制系统；2.接触器、接触器电源或MOC模块故障。

                - **hp_q013** [问题] 停止信号可能来自启动按钮、停止按钮、顺槽远程、端头站或遥控器。
                  - `按钮` → `hp_q014`
                    - **hp_q014** [问题] 请检查油泵启动按钮、停止按钮、总停按钮是否卡死在接通状态。
                      - `接通` → `hp_r011`
                        - **hp_r011** [结论] 油泵启动按钮、停止按钮或总停按钮存在卡死情况，均会造成无法启动。请检查卡死原因并酌情处理。
                      - `不通` → `hp_q015`
                        - **hp_q015** [问题] 油泵启动按钮、停止按钮和总停按钮均正常，请检查MOC-JX3.3（总停）、MOC-JX3.4（泵启）、MOC-JX3.5（泵停）上是否有DV24V。

                                  - `正常` → `hp_r014`
                                    - **hp_r014** [结论] 控制变压器输出132V（220V）电压正常，请检查控制变压器到模块和接触器之间的线路，找到断点处理。若供电线路没有问题，请直接更换接触器。
                                  - `没有` → `hp_q018`
                                    - **hp_q018** [问题] 控制变压器输出132V（220V）端口没有电压，请检查控制变压器输入电压是否正常。
                                      - `正常` → `hp_r015`
                                        - **hp_r015** [结论] 控制变压器输入侧电压正常、输出侧没有电压，基本确定控制变压器已损坏，请更换控制变压器。
                                      - `没有` → `hp_r016`

                  - `其他原因` → **待补录（录屏未展示）**
              - `2` → `hp_q019`
                - **hp_q019** [问题] 在排除有停止信号进入系统后，手持短接线短接MOC-JX2.5和MOC-JX2.8，检查接触器是否吸合（非安全电压，注意安全）。

                  - `不吸合` → `hp_q017`
                    - **hp_q017** [问题] 短接后接触器不吸合，可能原因：1.接触器已损坏；2.电源或供电线路故障。请检查控制变压器输出132V（220V）是否正常。
                      - `正常` → `hp_r014`
                        - **hp_r014** [结论] 控制变压器输出132V（220V）电压正常，请检查控制变压器到模块和接触器之间的线路，找到断点处理。若供电线路没有问题，请直接更换接触器。
                      - `没有` → `hp_q018`
                        - **hp_q018** [问题] 控制变压器输出132V（220V）端口没有电压，请检查控制变压器输入电压是否正常。
                          - `正常` → `hp_r015`
                            - **hp_r015** [结论] 控制变压器输入侧电压正常、输出侧没有电压，基本确定控制变压器已损坏，请更换控制变压器。
                          - `没有` → `hp_r016`
