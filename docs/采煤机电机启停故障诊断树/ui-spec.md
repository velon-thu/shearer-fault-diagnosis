# 小程序 UI 复刻规格

## 页面结构

- 微信小程序竖屏单页诊断界面。
- 顶部导航栏为浅青色，居中显示“采煤机维修指南”，左侧保留返回箭头。
- 主问题卡片为浅黄色背景、绿色圆角描边。
- 问题正文使用红色粗体并居中显示。
- 诊断选项使用蓝色粗体，均匀分布在问题卡片底部。
- 模块名称使用深青色粗体，位于问题卡片下方居中显示。
- “上一步”属于通用导航，不得写入诊断树业务选项。

## 交互要求

1. 以 `diagnosis-trees.yaml` 或 `diagnosis-trees.json` 作为唯一业务逻辑数据源。
2. 页面只维护 `currentNodeId` 与 `historyStack`，不得为每个节点单独硬编码页面。
3. 点击普通选项后，根据 `next` 跳转；点击“上一步”弹出历史栈。
4. `next: null` 的分支显示“该分支待补录”，不得由模型或程序自行补全。
5. `severity: warning` 或节点 `notes` 中包含高风险操作时，先弹出安全确认页。
6. 结果节点只显示处理建议和“上一步/返回首页”，不再显示诊断选项。

## 建议数据组件

- `QuestionCard`：问题文字、选项按钮、安全提示。
- `ResultCard`：诊断结论、风险级别、来源节点。
- `SafetyGate`：带电测量、短接、拆线、绝缘测试前的安全确认。
- `DiagnosisEngine`：读取树数据、执行跳转、维护历史栈。
