# 诊断路径验收测试

每条测试从模块起始节点开始。按“选择路径”依次点击，应抵达“预期结果”节点。待补录分支只验证程序显示占位提示，不允许自动猜测。

## 调高泵启停故障

### TC-001
- 模块：调高泵启停故障
- 选择路径：有 → 已启动 → 可以 → 有 → 有24V
- 预期结果：`hp_r001`：在泵接触器吸合后，MOC-JX4.7上可以测量到F+24V，说明电源及泵接触器辅助触点正常。在确认MOC-JX4插头没有问题后，请直接更换MOC模块。

### TC-002
- 模块：调高泵启停故障
- 选择路径：有 → 已启动 → 可以 → 有 → 没有
- 预期结果：`hp_r002`：请依次检查F24V到泵接触器辅助触点、再由辅助触点到MOC-JX4.7之间的线路，找到断路点并处理。

### TC-003
