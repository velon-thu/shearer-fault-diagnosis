# UI 复刻规格

## 页面布局

- 微信小程序竖屏页面，参考录屏尺寸比例约 572×1080。
- 顶部导航栏为浅青色，中央标题为“采煤机维修指南”，左侧为返回箭头。
- 主问题卡片采用浅黄色背景、绿色粗边框和小圆角。
- 问题/结论文字为红色、粗体、居中，字号根据内容长度自动缩放，不能溢出卡片。
- 诊断选项位于卡片底部，蓝色粗体；“上一步”始终位于底部中央。
- 卡片下方模块标题为深青色：“系统牵引故障”。
- 页面主体背景为近白色，不增加额外图标、动画或装饰。

## 交互规则

1. 只创建一个通用诊断页面，通过 `currentNodeId` 读取 YAML/JSON 节点。
2. 点击业务选项时，把当前节点压入 `historyStack`，再跳转到 `next`。
3. 点击“上一步”时弹出历史栈并恢复前一节点。
4. 结论节点只显示结论文字与“上一步”。
5. 不得把“上一步”写成诊断选项，不得在代码中硬编码每一页。
6. 高风险诊断结论页面应固定显示安全提示，并可增加“已阅读安全提示”确认，但不能改变原诊断逻辑。
