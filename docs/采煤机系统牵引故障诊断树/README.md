# 文件说明

本包由 `系统牵引故障.mp4` 提取，包含完整的系统牵引故障诊断树。

- `diagnosis-tree.yaml`：推荐直接喂给编码 AI，作为业务逻辑唯一数据源。
- `diagnosis-tree.json`：与 YAML 等价，适合小程序直接加载。
- `diagnosis-tree.md`：人类可读版；最前面已加入采煤机制动系统与松闸确认调试说明。
- `acceptance-tests.md`：38 条完整根到结论测试路径。
- `ui-spec.md`：根据录屏整理的界面与交互规格。
- `prompt-for-coding-ai.md`：可直接交给 Codex / Claude Code / Cursor 的实现指令。
- `source-frames/`：每个逻辑节点对应的原始录屏截图。
- `raw/page-index.csv`：节点、时间戳和截图索引。
- `raw/transition-log.csv`：所有选项跳转关系。

## 推荐实现

只做一个通用诊断页面，由 `currentNodeId` 渲染节点；使用 `historyStack` 实现“上一步”。不要给每个问题单独建页面。

## 重要安全说明

本资料用于复刻原小程序的诊断逻辑，不替代矿方安全规程、设备说明书或专业人员判断。涉及 24V、220V、380V/660V 测量、绝缘测试、短接触点、拆装插头等操作时，必须由具备资质的人员执行停电、验电、放电、闭锁挂牌等措施。原页面中的“临时短接”内容仅按录屏原文保留，不应被 AI 或小程序视为可直接执行的操作授权。
