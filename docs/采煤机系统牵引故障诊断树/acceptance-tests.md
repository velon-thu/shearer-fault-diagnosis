# 系统牵引故障诊断路径测试

> 每一条路径都应从 `q01` 开始并到达一个结论节点。测试时同时验证“上一步”能够逐级返回。

## 路径 01 → `r01`

- `q01` 选择 **绿色** → `q02`
- `q02` 选择 **1** → `q03`
- `q03` 选择 **吸合** → `q04`
- `q04` 选择 **红色（有）** → `r01`
- 最终结论：牵电状态红色（小屏幕提示牵引系统未送电，请查明原因），此故障为HPC模块未收到牵引接触器吸合的反馈信号。电路结构：电源模块F24V→牵引接触器辅助触点→牵引接触器辅助触点→HPC-JX3.10。请按这个回路找到断开点处理即可。临时处理也可以短接HPC-JX3.10和HPCJX2.1。
