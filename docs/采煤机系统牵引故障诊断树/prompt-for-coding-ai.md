# 给编码 AI 的实现指令

读取本目录中的 `diagnosis-tree.yaml`，并将它作为“系统牵引故障”业务逻辑的唯一数据源。

请开发一个微信原生小程序页面，要求：

1. 使用 WXML、WXSS、TypeScript/JavaScript 实现一个通用诊断卡片组件。
2. 使用 `currentNodeId` 动态渲染问题、结论和业务选项。
3. 使用 `historyStack` 实现“上一步”，不要为每个节点创建独立页面。
4. 严格按照 YAML 中的 `options[].next` 跳转，禁止自行补充、改写或合并诊断结论。
5. UI 严格参考 `ui-spec.md` 和 `source-frames/`，保留“采煤机维修指南”和“系统牵引故障”标题。
6. 对涉及电压测量、绝缘测试、短接触点的结论显示固定安全提示；安全提示不能替代或改变原文。
7. 编写自动化测试，覆盖 `acceptance-tests.md` 中的全部根到结论路径，并验证每一步的返回功能。
8. 诊断数据与页面代码分离，后续新增节点只修改 YAML/JSON，不修改页面组件。
